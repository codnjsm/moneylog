# 주식거래 수익률(%) 표시

## 목표 / 하지 않는 것

- 목표: 주식거래 목록 카드와 거래 추가/수정 모달의 "예상 수익" 표시에 수익률(%)을 금액과 함께 보여준다.
- 하지 않는 것: 전체 누적 수익률 통계, 대시보드 반영, 매수가 0원 케이스에 대한 별도 안내 문구(그냥 "—" 표시로 충분).
